## 两条路径怎么选

- **极速实战路径(≈48小时不含阶段四 / 4–6周)**: 只学每门课"PM定制策略"指定的核心模块与关键章节, 跳过完整作业, 最快交付第一批真实产品。阶段四CS50 AI可跳过, 或做概念级通过(再加15–20小时)。
- **系统进阶路径(≈210–240小时含阶段四 / 15周基准, 约3–4个月)**: 在极速路径基础上, 深入完成高校经典工程课的作业与项目(CS50P 60h、CS50 SQL 63h、CS50W 96h、CS50 AI 45–60h等全量体量在此路径展开)。

判断标准: 在职时间紧、急于在团队内交付工具 → 极速路径; 每周能稳定投入13–15小时、想建立长期工程底座 → 系统路径。**可以中途切换**: 先极速跑通一轮, 再回头系统补课。

## 里程碑验收标准

- **里程碑1 本地自动化工具**: 模块化拆解清晰(数据读取/AI处理/文件导出三模块分离); 关键函数有前置/后置条件规约注释; 有单元测试。
- **里程碑2 AI工程脚手架仓库**: 结构化CLAUDE.md(模块边界/测试与Linter命令/禁止操作清单); .gitignore; 单元测试框架; GitHub Actions自动检查工作流。
- **里程碑3 内部工具上线**: 针对真实工作需求; 连接云端数据库; 生成公网或团队私有链接; 有同事实际使用。
- **里程碑4 AI应用毕业项目**: 系统路径完成CS50 AI毕业项目(用上至少两种课程技术)并领免费证书; 极速路径给里程碑3的工具加一个ML/NLP功能。
- **里程碑5 全栈网站上线**: 用户注册登录鉴权; 完整数据库CRUD; 响应式UI; Vercel自动部署。
- **里程碑6 跨平台App交付**: React Native (Expo) + TypeScript + Supabase; 与Web端共享数据库与鉴权体系; 完成真机调试与发布准备。

## 卡住怎么办

来自范德堡课程的铁律: **当Agent反复出错时, 优先修复提示词、上下文示例或验证闭环, 而非手动修补表层症状。** 陷入调试死循环时: 立即 /rewind 撤销对话步骤或 git restore 恢复代码 → /clear 清空无关上下文 → 补充缺失的上下文说明、示例或自动化测试 → 重新运行。完整八步守则见 [附录](07-附录_技术栈选型与AI开发SOP.md)。
