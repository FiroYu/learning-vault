# 03 · 阶段三: 内部工具、关系型数据库与自动化后端制作及上线(第5–6周)

> [专题总览](README.md) · [学习路径总览](00-学习路径总览.md) · 上一阶段 [阶段二](02-阶段二_工程工具链与Agent工程化.md) · 下一阶段 [阶段四](04-阶段四_AI原理.md)

**阶段目标**: 具备独立设计关系型数据库表结构(Schema)的能力, 并能结合AI在数小时内开发、测试并上线可供团队日常使用的内部数据看板、管理后台或AI业务工具。

**为什么先做内部工具**: 在挑战复杂的ToC商业网站或移动App之前, 先从企业内部工具(数据运营看板、CRUD管理后台、自动化报表工具、AI业务助手)切入是性价比最高的选择——内部工具对复杂前端动效要求低, 但对数据查询准确性、表单交互效率与快速上线能力要求高, 正好匹配PM的能力结构。

## 课程详情

### 1. SQLBolt 交互式教程 & CS50's Introduction to Databases with SQL

| 项 | SQLBolt | CS50 SQL |
|---|---|---|
| 机构 | SQLBolt | Harvard University · Carter Zenke |
| 形式与费用 | 完全免费 | 完全免费 |
| 学时 | 19关网页交互约3–4小时 | 7周课, 约9小时/周, 共63小时(全量) |
| 链接 | <https://sqlbolt.com/> | <https://cs50.harvard.edu/sql> |

**核心内容**:
- **SQLBolt**: 从基础SELECT查询到多表JOIN与子查询的19节实战练习。
- **CS50 SQL**: 系统覆盖七大主题——查询(Querying)、表关联(Relating)、Schema设计与数据正规化(Designing)、写入(Writing)、视图(Viewing)、索引优化(Optimizing)、扩展连接Python(Scaling)。

**PM定制学习策略**: 掌握软件核心数据骨架。
1. 先花3–4小时通关SQLBolt, 掌握基础查询语法
2. 再重点挑学CS50 SQL的 **Designing**(如何设计消除冗余的表结构与主外键)与 **Optimizing**(索引优化)章节——让你能为AI写出严谨的数据库Schema规约
3. 系统路径: 补Writing(数据写入)单元, 完整走7周

### 2. Streamlit 官方教程与 Build with Coding Agents 指南

| 项 | 内容 |
|---|---|
| 技术栈 | Python, Streamlit, Pandas, SQLite/PostgreSQL, Streamlit Cloud |
| 形式与费用 | 官方文档与交互教程完全免费(约4–6小时掌握核心) |
| 链接 | 入门 <https://docs.streamlit.io/get-started> · AI Agent专项 <https://docs.streamlit.io/develop/concepts/ai-agents/coding-agents> · 建App教程 <https://docs.streamlit.io/get-started/tutorials/create-an-app> |

**核心内容**: 纯Python构建数据看板、多页面应用(Multipage Apps)与CRUD表单; 涵盖侧边栏(st.sidebar)、多列容器(st.columns)、数据缓存(@st.cache_data)。2026核心特性:
- 项目内运行 `streamlit skills` 即可为Claude Code / Cursor安装官方匹配当前版本的专家技能包(/developing-with-streamlit)
- 开启实验性 `server.enableAgentApi = true` 后, Agent可在改完代码后自动运行真实Streamlit实例并操作筛选器校验结果

**PM定制学习策略**: **内部工具开发首选**。无需购买第三方付费课, 直接跟官方文档与streamlit skills边做边学。完成后将代码与requirements.txt推至GitHub, 登录 <https://share.streamlit.io> 即可3步免费部署上线。

### 4. FastAPI 官方教程 + Supabase 全托管后端实战

| 项 | 内容 |
|---|---|
| 技术栈 | Python, FastAPI, Pydantic, Supabase (PostgreSQL + Auth) |
| 形式与费用 | 官方文档与社区教程免费开放(核心入门约4–6小时) |
| 链接 | FastAPI教程 <https://fastapi.tiangolo.com/tutorial/> · Supabase实战参考 <https://www.wearetandem.ai/en/blog/tools/supabase-internal-tool-tutorial> |

**核心内容**:
- **FastAPI**: 路径/查询参数、Pydantic数据模型校验、依赖注入与异步REST API接口构建。
- **Supabase**: 免服务器运维的云端PostgreSQL数据库、用户账户注册登录管理与数据访问安全规则(Access Rules)。

**PM定制学习策略**: 生产级内部工具后端组合。当内部工具需要严格的账号权限管控或跨系统提供API时, 采用"Streamlit/前端 + FastAPI + Supabase"架构, 直接复用Supabase现成的数据库与用户鉴权模块。

## 里程碑3: 内部工具上线

**任务**: 针对你当前PM工作中的真实需求, 独立制作并上线一个企业级内部工具。候选方向:
- 连接云端数据库的业务指标异常监控与配置后台
- 内部AI文档处理工作台

**推荐路径**: SQLBolt/CS50 SQL设计好Schema → Streamlit + Claude Code(带streamlit skills)构建 → 推GitHub → Streamlit Community Cloud上线 → 生成链接交付同事。

**验收清单**:
- [ ] 数据库Schema有明确主外键设计(能画出ER图)
- [ ] 工具有真实的团队使用场景
- [ ] 已通过share.streamlit.io或HF Spaces上线
- [ ] 至少1位同事实际使用并给出反馈
