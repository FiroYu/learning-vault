## 课程详情

### 1. Full Stack Open (Part 0 + 精选章节)

| 项 | 内容 |
|---|---|
| 机构 | University of Helsinki (赫尔辛基大学) |
| 形式与费用 | 官网完全免费开源, 持续更新(共15个Part, 0–14) |
| 学时 | Part 0约2小时 |
| 链接 | <https://fullstackopen.com/en/> · Part 0直达 <https://fullstackopen.com/en/part0/general_info/> |

**核心内容**: Part 0(Web应用基础)深入解析传统Web页面与现代单页应用(SPA)在浏览器与服务器之间的HTTP请求通信、DOM渲染与数据流转。后续涵盖React(Part 1–2)、Express后端(Part 3–4)、TypeScript(Part 9)、React Native(Part 10)、CI/CD(Part 11)、Docker(Part 12)、关系型数据库(Part 13)与Next.js(Part 14)。

**PM定制学习策略**: **必读Part 0**——全网把"浏览器点击按钮后, 前后端到底发生了什么"讲得最透彻的入门指南。其余章节(Part 9 TypeScript、Part 11 CI/CD、Part 12 Docker)作为参考书按需查阅, 无需从头刷完。

### 2. React Foundations & Learn Next.js (Build a Full-Stack Dashboard App)

| 项 | 内容 |
|---|---|
| 机构 | Vercel / Next.js官方 |
| 形式与费用 | nextjs.org/learn免费交互式课程 |
| 学时 | 前置React基础 + 16章Next.js实战, 约12–15小时 |
| 链接 | <https://nextjs.org/learn> · Dashboard项目 <https://nextjs.org/learn/dashboard-app> |

**核心内容**: 从零构建并上线一个完整的全栈财务管理网站——公共首页、登录鉴权页(NextAuth.js)、受保护的仪表盘路由、连接云端PostgreSQL(Neon/Supabase/Prisma)、数据获取与流式渲染、基于URL参数的搜索与分页、React Server Actions实现发票增删改(CRUD)、服务端表单校验与无障碍优化、404错误处理与社交分享Metadata。

**PM定制学习策略**: **独立网站开发第一主力课(强烈必学)**。先学《React Foundations》掌握组件(Components)、属性(Props)、状态(State)、Hooks、服务端组件(Server Components)与Suspense; 再逐章完成16章Dashboard项目。

**为什么选Next.js栈**: Next.js + TypeScript + Tailwind + Vercel是目前AI编程Agent支持度极高、模板极丰富的全栈技术栈(官方提供Prisma Postgres Auth Starter与shadcn/ui管理后台模板), 推送GitHub即可自动部署并生成PR预览链接。

### 3. CS50's Web Programming with Python and JavaScript (CS50W)

| 项 | 内容 |
|---|---|
| 机构 | Harvard University · Brian Yu |
| 形式与费用 | 哈佛OCW免费公开(9周教学内容+5个项目+毕业设计; 约6–9小时/周, 12周共约96小时) |
| 链接 | <https://cs50.harvard.edu/web> |

**核心内容**: 通过5个经典互联网产品原型贯穿全栈工程——Google搜索前端(P0)、Wikipedia百科(P1)、eBay电商拍卖(P2)、单页邮件客户端(P3)、类Twitter社交网络(P4)+自选毕业设计; 第7–8周专门讲授自动化测试、CI/CD、系统可扩展性与应用安全。

**PM定制学习策略**: 理解经典Web全栈架构与安全原则的标杆课, Brian Yu对概念拆解极其清晰。主攻Next.js栈可跳过Django语法细节, 只看四个专题周:
- **Week 0** — HTML/CSS响应式布局
- **Week 4** — 数据模型与数据库迁移(Migrations)思想
- **Week 6** — 用户界面交互
- **Week 7–8** — 测试、CI/CD、可扩展性与安全

系统路径: 完整做5个项目+毕业设计。

## 里程碑5: 独立全栈网站上线

**任务**: 使用 Next.js (App Router) + TypeScript + Tailwind CSS / shadcn/ui + Prisma/Supabase (PostgreSQL) + NextAuth.js + Vercel 技术栈, 在Claude Code辅助下独立开发并上线一个带用户注册登录、完整数据库CRUD与响应式UI的独立全栈网站。

**起步模板**(可直接基于Vercel官方):
- Prisma Postgres Auth Starter — <https://vercel.com/templates/next.js/prisma-postgres>

- [ ] 绑定GitHub后push主分支自动部署, PR有预览链接
- [ ] .env密钥未入库, 上线前Diff审查通过
- [ ] 移动端响应式UI正常
- [ ] (可选加分)加入一个AI功能, 用上阶段四原理
