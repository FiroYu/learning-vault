## 课程详情

### 1. AI Python for Beginners

| 项 | 内容 |
|---|---|
| 机构/讲师 | DeepLearning.AI / Coursera · Andrew Ng (吴恩达) |
| 形式与费用 | 官网及Coursera免费学习 |
| 学时 | 4个模块共17小时(4h+4h+4h+5h) |
| 链接 | <https://www.coursera.org/learn/ai-python-for-beginners> · <https://learn.deeplearning.ai/courses/ai-python-for-beginners> |

**核心内容**: Python基础语法、用Python自动化任务、读取处理自有文档与数据、调用第三方包与外部API; 全程内置AI助教解释概念与辅助调试, 模拟真实开发实践。

**PM定制学习策略**: 零基础破冰首选(必学)。你已有用代码工具的经验, Module 1(基础语法)快速浏览即可; 重点完成 Module 2(用Python自动化任务)、Module 3(读取并处理自有文档与数据)、Module 4(使用第三方包与调用外部API)——直接建立"人机结对写Python"的工作流习惯, 熟练掌握在AI助教配合下读取本地文件、调用大模型API并处理返回数据的基本功。

### 2. CS50's Introduction to Programming with Python (CS50P)

| 项 | 内容 |
|---|---|
| 机构/讲师 | Harvard University · David J. Malan |
| 形式与费用 | 哈佛OCW完全免费(含全套视频、9个习题集、毕业项目与免费证书) |
| 学时 | 10周内容, 3–9小时/周, 总计约60小时(全量) |
| 链接 | <https://cs50.harvard.edu/python/> |

**核心内容**: 函数、参数与返回值; 变量、类型与异常处理; 条件与布尔表达式; 循环; 对象与方法(OOP); 文件I/O与外部库。

**PM定制学习策略**: 比CS50x更适合PM(避开C语言与底层内存管理的陡峭曲线)。与吴恩达课程重合的基础语法2倍速速览, 重点精学四个专题:
- **Exceptions** — 理解程序报错机制与容错捕获(读懂AI代码的报错全靠它)
- **File I/O** — 文件读写
- **Libraries** — 外部库
- **Objects & Methods** — 建立面向对象封装认知

系统路径: 完整做9个习题集+毕业项目。极速路径: 只学上述四专题对应讲座与习题。

| 项 | 内容 |

**PM定制学习策略**: 选择性精读讲义, 无需重头做完所有图像作业。重点研读:
- **Lecture 3** — Function Calls and Decomposition(函数调用与问题拆解): 如何把庞大需求拆解为职责单一的小函数
- **Lecture 8** — Doctests(测试)
- **Lecture 13b** — Software Design(软件设计)
- (系统路径加学)Lecture 19–21 — 嵌套字典与列表数据结构(PM处理JSON/API返回数据的核心结构)

### 4. MIT 6.1020 Software Construction

| 项 | 内容 |
|---|---|
| 机构/讲师 | MIT · Max Goldman, Rob Miller等 |
| 形式与费用 | 官网公开著名的交互式在线讲义与内嵌练习(TypeScript版) |
| 学时 | 19+核心主题讲义(MIT 3-0-12学分课) |
| 链接 | TypeScript版讲义 <https://web.mit.edu/6.031/www/sp21/ts/> · 课程主页 <http://web.mit.edu/6.031/> |

**核心内容**: 软件构造三大准则——安全无Bug(Safe from bugs)、易读(Easy to understand)、易改(Ready for change); 规约与契约、测试先行(Test-first)、可变与不可变性、抽象数据类型(ADT)、异步Promise与并发。

**PM定制学习策略**: PM进阶架构思维的核心读物。重点精读并完成内嵌练习:
- **Reading 06 & 07** — Specifications & Designing Specifications(规约设计): 本课最重要准则"在写任何函数实现之前, 必须先写规约"
- **Reading 09** — Avoiding Debugging(通过静态类型、不可变性与契约预防Bug)
- (系统路径加学)Reading 08 — 可变性(Mutability); Promise异步机制
- 略过末尾高难度的多线程并发(Concurrency)单元

**为什么要碰TypeScript**: 熟悉静态类型声明语法(接口与类型注解)——TypeScript是后续网站与App开发的核心语言, 其编译期类型检查是防止AI写出参数拼写与结构错误的关键护栏。

## 里程碑1: Python自动化工具

**任务**: 独立规划并用AI辅助编写一个模块化拆解清晰的Python自动化工具。示例: 自动批量处理用户反馈文档并生成分类统计报告。

**架构要求**:
- 分为数据读取模块、AI处理模块、文件导出模块三层
- 为关键函数编写前置/后置条件规约注释
- 配单元测试

**验收清单**:
- [ ] 三模块分离, 单文件不超过~200行
- [ ] 关键函数有spec注释(前置条件/后置条件)
- [ ] 至少3个单元测试通过
- [ ] 能对一批真实文档跑出正确统计结果
